# RevitViewPlacer — Автоматизация альбома АР и Генплана ГП-1 по ГОСТ РК / СН РК (Revit 2025/2026)

Плагин для **Autodesk Revit 2025 / 2026** (`.NET 8.0`), автоматизирующий создание, оформление и компоновку полного комплекта рабочих чертежей марки **АР** и **ГП-1** на листах формата **А3 (Форма 3)** в соответствии с нормативами **ГОСТ 21.101-97**, **ГОСТ 21.501-93**, **ГОСТ 21.508-93** и **СН РК / СП РК**.

---

## Основные возможности

1. **Автоматическое формирование альбома листов А3 (`PlaceViewsCommand.cs`)**:
   - **Лист 1 — Обложка альбома** (`CoverSheetBuilder.cs`, семейство без штампа).
   - **Лист 2 — Общие данные (ЛОД)** (`KzGostSheetStyler.cs`): ведомость рабочих чертежей основного комплекта АР, ведомость ссылочных документов РК, таблица ТЭП здания и официальные общие указания.
   - **Лист 3 — Ситуационная схема (М 1:5000)** (`SituationPlanSheetBuilder.cs`).
   - **Лист 4 — Генеральный план ГП-1 (М 1:500)** (`GenerateDetailedSitePlanCommand.cs`, `SitePlanEditorWindow.cs`, `SitePlanAnalysisLayout.cs`): интерактивный редактор функциональных зон с возможностью добавления/удаления площадок, 3D-озеленение и благоустройство, роза ветров, экспликация и баланс территории.
   - **Планы этажей**: автоматическая расстановка марок помещений `ADSK_Марка_Помещение_ДваЗначения`, сквозная или поэтажная нумерация помещений по ГОСТ (`RoomRenumberEngine.cs`) и поэтажные экспликации помещений над основной надписью.
   - **Разрезы (`SectionSheetBuilder.cs`)**: автопостроение продольного (`1–1`) и поперечного (`2–2`) разрезов при их отсутствии, выносные «флажки» пирогов кровли и пола со стрелкой по ГОСТ, высотные отметки и ведомость конструкций.
   - **Фасады (`ElevationSheetBuilder.cs`)**: автопостроение 4 ортогональных фасадов вокруг здания (`Фасад в осях 1–N`, `N–1`, `А–Я`, `Я–А`) через `ElevationMarker` и таблица «Ведомость наружной отделки фасадов».
   - **Лист визуализации («РЕНДЕР»)** (`RenderSheetBuilder.cs`).

2. **Интеллектуальная работа с координационными осями (`GostGridManager.cs`)**:
   - Работает строго с существующими осями проекта (не создает лишних осей).
   - Переименовывает рабочие оси по ГОСТ 21.101-97: цифровые `1, 2, 3...` слева направо и буквенные `А, Б, В...` снизу вверх (исключая `Ё, З, Й, О, Х, Ц, Ч, Щ, Ъ, Ы, Ь`).
   - Выравнивает кружки осей на планах этажей (`1, 2, 3...` строго снизу, `А, Б, В...` строго слева) и строит две размерные цепочки (шаг осей + общий габарит между крайними осями).
   - Индивидуально на каждом этаже / разрезе / фасаде скрывает неиспользуемые оси.

## Быстрая установка для пользователей (без сборки кода)

1. Скачайте архив [`RevitViewPlacer_Setup.zip`](./RevitViewPlacer_Setup.zip) из репозитория.
2. Распакуйте его в любую папку и запустите **`Установить_Плагин.cmd`**.
3. Откройте Autodesk Revit 2026 (при запросе выберите **«Всегда загружать» / Always Load**).
4. Перейдите на вкладку **«Авторазмещение АР»**.

## Разработка и совместная работа через Git

### Требования для сборки
- **Windows 10 / 11 (x64)**
- **.NET 8.0 SDK**
- **Autodesk Revit 2026** (по умолчанию путь к API: `C:\Program Files\Autodesk\Revit 2026`). Если Revit установлен в другую папку, укажите `-p:RevitInstallDir="путь_к_Revit"`.

### 1. Клонирование репозитория (для коллеги)
```bash
git clone https://github.com/Nuraman-man/RevitViewPlacer.git
cd RevitViewPlacer
```

### 2. Сборка плагина и автоматическая установка в Revit
```powershell
dotnet build RevitViewPlacer.csproj -c Release
```
При сборке проект автоматически копирует `RevitViewPlacer.addin`, `RevitViewPlacer.dll` и семейства `.rfa` в `%APPDATA%\Autodesk\Revit\Addins\2026\`.

### 3. Сборка ZIP-дистрибутива
Для упаковки свежего архива `RevitViewPlacer_Setup.zip`:
- Запустите двойным кликом **`Собрать_Дистрибутив_для_Коллег.cmd`**  
  или выполните в PowerShell:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\BuildDistribution.ps1
  ```

### 4. Совместная работа с коллегой (Git Workflow)
1. **Перед началом работы** всегда забирайте свежие изменения с сервера:
   ```bash
   git pull origin main
   ```
2. **Для новой задачи или улучшения** (рекомендуется создать ветку или работать с коммитами):
   ```bash
   git status
   git add .
   git commit -m "Описание изменений"
   git push origin main
   ```

## Структура проекта

| Файл | Назначение |
|---|---|
| `App.cs` | Регистрация вкладки «Авторазмещение АР» и кнопок на ленте Revit |
| `PlaceViewsCommand.cs` | Главная команда пакетного создания и оформления альбома листов А3 |
| `GostStampHelper.cs` | Диалоговое окно настроек штампа ГОСТ РК, выбора видов и масштабов |
| `GostGridManager.cs` | Нумерация существующих осей по ГОСТ, выравнивание кружков, размерные цепочки и скрытие лишних осей |
| `ViewGostStyler.cs` | СПДС-оформление видов (высотные отметки, линия земли, флажки пирогов пола и кровли) |
| `SectionSheetBuilder.cs` | Автопостроение разрезов `1–1` и `2–2` и экспликации конструкций |
| `ElevationSheetBuilder.cs` | Автопостроение 4 фасадов по сторонам света и крайним осям |
| `GenerateDetailedSitePlanCommand.cs` | Генерация 3D/2D генерального плана ГП-1, озеленения, благоустройства и ТЭП |
| `SitePlanEditorWindow.cs` | Интерактивный 2D-редактор границ участка и функциональных зон генплана |
| `KzGostSheetStyler.cs` | Оформление листа «Общие данные» (ЛОД), таблиц ТЭП и ведомостей по СН РК |
| `SheetLayoutEngine.cs` | Расчет масштабов по ГОСТ и компоновка видовых экранов на листе А3 |
| `RoomTagManager.cs` / `RoomRenumberEngine.cs` | Замена марок помещений на ADSK и упорядочивание нумерации помещений |
